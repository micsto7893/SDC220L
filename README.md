# Multi-Function Calculator — SDC220L

**Creator:** Michael Stoller  
**Course:** SDC220L  

## Project Summary

The Multi-Function Calculator is a C# console application developed over the course of SDC220L. 

## Features

- Addition, subtraction, multiplication, and division using two numbers.
- Multi-number operations for 2–10 numbers with the same selected operator, evaluated **left to right**.
- Store, retrieve, replace, and clear a single numeric value.
- Save up to 10 numbers.
- Input retry for nonnumeric entries and divide-by-zero errors using exception handling.
- Menu loops until the user chooses Exit.

## How to Run

Requires the **.NET 10 SDK**.

1. Open this project folder in VS Code or a terminal.
2. Run `dotnet run`.
3. Choose a numbered option and follow the prompts.
4. Select **8. Exit** to close the program.
